description: "Your interface language and the language of each document."
---

Signyd supports **English** and **Español**.

## Interface language

The language switcher in the app shell is **personal**. It changes labels, menus, and settings for you only. It does not change emails already sent or the language of a document.

## Document language

Set **Document language** when you send a request (English or Español). That choice controls:

- Invitation and reminder emails
- The signing legal notice
- The audit trail language for that request

Change it per document. Teammates can keep a different interface language.
