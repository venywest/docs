title: "Lista de documentos"

---

Ruta: `/documents`

La lista muestra documentos de tu organización. Puedes abrir una solicitud, crear una nueva o archivar archivos que ya no necesitas en la lista activa.

## Estados

| Estado | Significado |
| --- | --- |
| Borrador | Subido, no enviado |
| Enviado | Salieron las invitaciones |
| Parcialmente firmado | Al menos un firmante terminó |
| Completado | Todos los firmantes requeridos terminaron |
| Anulado | Cancelado antes de completar |
| Caducado | Terminó la ventana de firma |

## Acciones

- **+ Documento** — nueva solicitud
- Abre una fila para ver el [detalle](/es/documents/detail)
- **Archivar** una solicitud completada o sin uso

Los documentos firmados no se pueden eliminar. Archívalos. Los archivados se eliminan solos a los **30 días**.
