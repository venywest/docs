---

Coloca campos en el paso 2 de preparar. Elige el destinatario, un tipo y pulsa la página.

## Tipos de campo

| Tipo | Uso |
| --- | --- |
| Firma | Al menos un campo de firma por solicitud |
| Iniciales | Cuenta como campo de firma |
| Nombre | Se rellena del destinatario cuando es posible |
| Correo | Se rellena del correo del destinatario |
| Fecha de firma | Se llena cuando ese destinatario firma |
| Texto | Texto corto |
| Casilla | Sí / no |

## Ajustes del campo

Abre **Ajustes del campo** para:

- Marcarlo **requerido** u opcional
- Moverlo o cambiar el tamaño
- Validar campos de texto
- Elegir métodos de firma (dibujar, escribir o subir) si tu plan lo permite

Asigna cada campo de firma a un destinatario. La firma secuencial usa las mismas posiciones; Signyd solo escribe al siguiente cuando **Pedir firmas en orden** está activo.
