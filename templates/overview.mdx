title: "Templates"

Route: `/templates`

Save a document layout so the next request starts with the same pages and fields.

## Create a template

1. Open **Templates** or choose **Open templates** on upload.
2. Upload a PDF or Word file (same limits as a regular request: **15 MB**, no open password).
3. Place fields and assign them to signer roles.
4. Save a name.

When you start a request from a template, Signyd may require a minimum number of signers so every role is filled.

## Use a template

On `/documents/new`, select **Open templates**, pick a layout, then add real recipients and send as usual.
