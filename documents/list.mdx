Route: `/documents`

The list shows documents in your organization. You can open a request, start a new one, or archive files you no longer need in the active list.

## Statuses

| Status | Meaning |
| --- | --- |
| Draft | Uploaded, not sent |
| Sent | Invitations went out |
| Partially signed | At least one signer finished |
| Completed | Every required signer finished |
| Voided | Canceled before completion |
| Expired | The signing window ended |

## Actions

- **+ Document** — start a new request
- Open a row to see [document detail](/documents/detail)
- **Archive** a completed or unused request

Completed (signed) documents cannot be deleted. Archive them. Archived files are removed automatically after **30 days**.
