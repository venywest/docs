---

Place fields on step 2 of prepare. Select the recipient in the toolbar, choose a type, then click the page.

## Field types

| Type | Use |
| --- | --- |
| Signature | Required for at least one field per request |
| Initials | Counts as a signing field |
| Name | Prefills from the recipient when possible |
| Email | Prefills from the recipient email |
| Date signed | Filled when that recipient signs |
| Text | Short free text |
| Checkbox | Yes / no |

## Field settings

Open **Field settings** to:

- Mark the field **required** or optional
- Resize or move it
- Set validation on text fields
- Choose allowed signature methods (draw, type, or upload) when your plan supports them

Assign every signing field to a specific recipient. Sequential signing still uses the same placements; Signyd only emails the next person when **Request signatures in order** is on.
